🐍 Java Snake Game

A classic Snake Game developed using Java and Java Swing. Control the snake, collect apples, grow longer, and try to achieve the highest score without hitting yourself!

🎮 About the Project

This project is a simple 2D Snake Game built using Java Swing. It demonstrates object-oriented programming, event handling, keyboard controls, graphics rendering, and game logic in Java.

✨ Features
Classic Snake Game gameplay
Keyboard-based movement
Apple collection and snake growth
Score tracking
Collision detection
Game over functionality
Simple graphical user interface using Java Swing
🛠️ Technologies Used
Java
Java Swing
AWT (Abstract Window Toolkit)
Object-Oriented Programming

🚀 How to Run the Project
1. Clone the Repository
bash
git clone https://github.com/25wh1a05a5-uh/Java-lab-Project--Snake-Game.git

2. Navigate to the Project Folder
bash
cd Java-lab-Project--Snake-Game

3. Compile the Java Files
bash
mkdir -p out
javac -d out $(find src -name "*.java")

4. Run the Game
bash
java -cp out com.zetcode.Snake

🎯 How to Play
⬆️ UP Arrow: Move upward.
⬇️ DOWN Arrow: Move downward.
⬅️ LEFT Arrow: Move left.
➡️ RIGHT Arrow: Move right.
🍎 Collect apples to increase your score and snake length.
Avoid collisions with yourself.
